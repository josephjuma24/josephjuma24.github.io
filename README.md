## 🚀 Getting Started

### Prerequisites
- Modern web browser
- Git (for cloning the repository)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/josephjuma24/josephjuma24.github.io.git
   cd josephjuma24.github.io
   ```

2. **Open in browser**
   - Open `index.html` in your web browser
   - Or use a local server for better development experience:
     ```bash
     # Using Python
     python -m http.server 8000

     # Using Node.js
     npx serve .

     # Using PHP
     php -S localhost:8000
     ```

3. **Navigate the site**
   - Start with `index.html` for the homepage
   - Use the navigation menu to explore different sections
   - All pages are self-contained and link to each other
